DAWG

Detecting Adversarial Webpages against Visual Web Agents v0.1 · in progress

DAWG is a binary classifier trained to flag rendered web pages whose pixels have been adversarially modified to fool MolmoWeb, a state-of-the-art screenshot-only visual web agent. A real attacker can serve different content to detected agents than to humans, so a defender never sees a clean reference image — the discriminator must work from a single live screenshot.

We generate training data by running white-box PGD attacks against MolmoWeb-4B's vision tower on synthetic web pages (news, e-commerce, blog, login, dashboard, restaurant, search), producing matched (clean, attacked) screenshot pairs at scale. The discriminator (DINOv2-base + MLP head, LoRA fine-tune) is decoupled from MolmoWeb itself, so it ports to any screenshot VLM agent.
